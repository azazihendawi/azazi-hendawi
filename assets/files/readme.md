# Project files go here

Add your real files and keep the paths matching `js/script.js`.

## Examples

| File | Path in script |
|------|----------------|
| Packet Tracer project | `assets/files/Cisco_Enterprise_Network.pkt` |
| PDF documentation | `assets/files/Network-Documentation.pdf` |
| Lab configs | `assets/files/labs/VLAN_Config.txt` |
| Certificate PDF | `assets/files/CCNA-Certificate.pdf` |

Create a `labs/` subfolder for lab-specific files:

```text
assets/files/labs/
├── VLAN_Lab.pkt
├── VLAN_Config.txt
├── VLAN_Lab.pdf
└── ...
```

Placeholder download links will 404 until you add the actual files — that is expected.
